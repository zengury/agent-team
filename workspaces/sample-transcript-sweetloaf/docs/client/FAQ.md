**面向陈老板和全体店员**

> 版本：1.0 | 更新日期：2026年5月

## 一、系统基础问题

### Q1: 这套系统是做什么的？能帮我解决什么问题？

**A:** 这套系统是专门为SweetLoaf烘焙坊量身定制的运营管理工具。它能帮您解决三个最头疼的问题：

1. **库存管理乱、损耗高** — 系统实时记录每一袋面粉、每一个面包的进出，自动提醒您什么时候该进货、进多少货。目标是帮您把每天扔掉的面包从现在的15%-20%降到10%以下。
2. **运营效率低、容易出错** — 订单不用再手写在小纸条上，排班不用再用Excel手工做。所有信息都在系统里，一目了然，再也不会漏单、记错日期。
3. **客户留不住、复购低** — 建立会员体系，记录顾客的消费习惯，自动给老顾客发优惠券和生日祝福，让顾客愿意常来。

简单说就是：**帮您省钱（减少损耗）、省时间（提高效率）、多赚钱（留住客户）。**

### Q2: 我需要买电脑或服务器吗？

**A:** 您不需要买任何新设备。系统是网页版的，用现有的电脑、手机、平板都能用。

- **电脑：** 任何能上网的电脑都行，Windows、Mac都可以
- **手机：** 安卓和iPhone都支持
- **平板：** iPad或安卓平板都可以

系统会部署在云服务器上（技术人员会帮您搞定），您只需要一个浏览器就能访问。

### Q3: 我不会用电脑，能学会吗？

**A:** 完全没问题！这套系统的设计原则就是"简单好用"。您只需要会：

- 打开浏览器（就像打开网页一样）
- 输入网址
- 点击按钮
- 输入文字

如果您会用手机刷视频、发Line消息，那您一定能学会用这套系统。我们还会安排一次现场培训，手把手教您和店员们怎么操作。一般用上两三天就熟练了。

### Q4: 系统安全吗？数据会不会丢失？

**A:** 非常安全。我们做了以下保障：

1. **账号密码保护** — 每个员工有自己的账号，只能看到自己权限范围内的信息
2. **数据自动备份** — 系统每天凌晨会自动备份数据，即使服务器出问题，数据也不会丢
3. **HTTPS加密** — 所有数据传输都经过加密，别人无法窃取
4. **本地存储** — 数据存储在您自己的服务器上，不会被第三方获取

### Q5: 如果系统出问题了怎么办？

**A:** 我们提供以下支持渠道：

- **工作时间（周一至周五 9:00-18:00）：** 拨打技术支持电话或发Line消息，一般30分钟内响应
- **紧急问题（系统完全无法使用）：** 24小时紧急联系电话
- **自助排查：** 可以先试试刷新页面、检查网络、重启电脑，很多小问题都能解决

## 二、库存管理相关问题

### Q6: 每天要花多少时间记录库存？会不会很麻烦？

**A:** 每天只需要花**5-10分钟**。具体来说：

- **打烊前（3分钟）：** 登记今天报废了多少面包
- **进货时（2分钟）：** 供应商送货时，在系统里点一下入库
- **生产时（2分钟）：** 后厨领用原料时，登记一下出库

比起以前"凭感觉进货、凭记忆算损耗"，这点时间投入非常值得。而且系统会自动算出建议采购量，帮您省去了算账的时间。

### Q7: 如果店员忘记登记入库或出库怎么办？

**A:** 刚开始使用时，大家可能会忘记。我们建议：

1. **养成习惯：** 把登记流程贴在仓库和收银台旁边，提醒大家
2. **每日核对：** 店长每天下班前花2分钟核对一下当天的记录是否完整
3. **系统提醒：** 如果某天没有记录任何生产或报废数据，系统会弹出提醒

一般坚持一周，大家就养成习惯了。

### Q8: 库存预警的数字准不准？我可以自己调吗？

**A:** 系统会根据历史数据自动计算建议的安全库存和采购量，但您完全可以手动调整。

**调整方法：**
1. 点击「库存管理」→「原料列表」
2. 找到想调整的原料
3. 点击「设置安全库存」
4. 输入您认为合适的数字

**举个例子：** 系统建议高筋面粉的安全库存是50公斤，但您觉得夏天用量大，想调到60公斤，直接改就行。

### Q9: 系统能帮我算出每天应该做多少面包吗？

**A:** 目前系统会根据历史销量数据，给出**建议生产量**。比如：

- 过去7天，周一平均卖出40个桂圆核桃面包
- 系统会建议：周一生产45个（留一些余量）
- 如果天气预报说明天会下雨（影响客流），系统会建议减少生产量

这个功能需要先用一段时间积累数据，数据越多，预测越准。一般用一个月后，建议就会比较准确了。

### Q10: 三家店的库存是分开管理的吗？

**A:** 是的！每家店的库存是独立管理的：

- **东区总店**（含中央厨房）：可以看到原料和成品的完整库存
- **中西区分店**：只能看到自己店的库存
- **南区分店**：只能看到自己店的库存

但**陈老板的账号**可以同时查看三家店的库存情况，在一个界面上就能对比。

## 三、订单管理相关问题

### Q11: 顾客打电话来订蛋糕，我怎么记到系统里？

**A:** 操作非常简单：

1. 打开系统，点击「订单管理」→「新建订单」
2. 输入顾客姓名和电话
3. 选择要的产品（比如"芒果乳酪蛋糕"）
4. 输入数量和取货日期
5. 备注特殊要求（比如"不要芒果酱"）
6. 点击「确认」

整个过程不超过30秒，比用纸笔记录还快，而且再也不会弄丢。

### Q12: 会不会出现两个顾客在同一时间订了同一个蛋糕的情况？

**A:** 不会！系统会自动检查库存。比如：

- 芒果乳酪蛋糕每天限量20个
- 已经有18个被预订了
- 当第19个顾客来订时，系统会提醒您："该产品当天仅剩2个可预订名额"
- 如果20个都订完了，系统会提示"该产品当天已售罄"

这样就不会出现"收了钱却做不出来"的尴尬情况了。

### Q13: 公司团购订单怎么处理？

**A:** 团购订单和普通订单一样处理，只是数量更大。系统会特别标注：

- 在日历上用不同颜色显示团购订单（比如蓝色）
- 提前3天提醒您："3天后有50个礼盒的团购订单需要交付"
- 如果团购订单量太大，系统会建议您提前准备原料

### Q14: 订单可以修改或取消吗？

**A:** 可以的。在订单列表中找到要修改的订单：

- **修改：** 点击「编辑」，可以改产品、数量、取货时间
- **取消：** 点击「取消订单」，系统会标记为"已取消"
- **注意：** 如果订单状态已经是"制作中"或"已完成"，需要联系店长确认后才能修改

## 四、排班管理相关问题

### Q15: 排班表怎么用？比Excel好在哪？

**A:** 排班表就像一张电子表格，但比Excel好用得多：

| 功能 | 以前用Excel | 现在用系统 |
|:---|:---|:---|
| 排班操作 | 手动输入名字、复制粘贴 | 拖拽式操作，点一下就能排 |
| 员工调班 | 员工找老板 → 老板改Excel | 员工自己申请 → 老板手机审批 |
| 请假管理 | 手写请假单 → 老板改排班 | 线上提交 → 自动更新排班 |
| 查看排班 | 打印出来贴墙上 | 手机随时查看 |
| 冲突检测 | 全靠人工检查 | 自动检测，不会出现两个人同时请假 |

### Q16: 员工怎么用手机申请调班？

**A:** 员工操作步骤：

1. 打开手机浏览器，登录自己的账号
2. 点击「排班」→「申请调班」
3. 选择要调换的日期和班次
4. 选择想跟谁换班（系统会显示可换班的人员名单）
5. 填写调班原因
6. 点击「提交申请」

提交后，您（老板）的手机会收到一条审批通知，点一下「批准」或「拒绝」就行了。

### Q17: 如果有人临时请假，怎么找人顶班？

**A:** 系统有个"找人顶班"功能：

1. 员工在系统里提交请假申请
2. 系统会自动检查当天其他员工中，谁没有排班、谁有空
3. 列出可以顶班的人员名单
4. 您可以选择合适的人，系统会自动发送通知给他
5. 对方确认后，排班表自动更新

整个过程从以前可能要打好几个电话，变成在手机上点几下就搞定。

## 五、会员管理相关问题

### Q18: 怎么帮顾客注册会员？

**A:** 顾客结账时，店员可以问一句："要不要注册会员？以后可以积分换优惠哦！"

注册方法：
1. 在收银界面点击「注册会员」
2. 输入顾客的手机号码
3. 输入顾客的姓名（如果顾客愿意提供）
4. 点击「确认」

整个过程只需要10秒钟。顾客以后报手机号就能积分。

### Q19: 会员有什么好处？顾客为什么要注册？

**A:** 会员可以享受以下好处：

1. **消费积分：** 每消费10元积1分，100分可以抵10元
2. **生日优惠：** 生日当月可领取一张免费蛋糕券
3. **新品试吃：** 新品上市时，会员可以优先试吃
4. **专属折扣：** 不定期推送会员专属优惠券

这些好处会印在店内的宣传海报上，鼓励顾客注册。

### Q20: 我怎么给会员发优惠券？

**A:** 有两种方式：

**方式一：手动发送**
1. 在会员列表中找到想发优惠的顾客
2. 点击「发送优惠券」
3. 选择优惠内容（比如"满100减20"）
4. 点击「发送」
5. 顾客会收到短信或Line消息通知

**方式二：自动发送（推荐）**
系统可以设置自动规则，比如：
- 会员生日前3天，自动发送生日优惠券
- 会员超过30天没来消费，自动发送"欢迎回来"优惠券
- 新品上市时，自动通知所有"面包爱好者"标签的会员

设置好规则后，系统会自动运行，您什么都不用管。

### Q21: 系统怎么知道顾客喜欢买什么？

**A:** 系统会根据顾客的消费记录，自动分析出他的消费偏好，并打上标签。比如：

- 如果张小姐每周都买面包，很少买蛋糕，系统会给她打上「面包爱好者」的标签
- 如果李先生每次来都买最贵的蛋糕，系统会给他打上「高客单价客户」的标签
- 如果王太太经常买给孩子吃，系统会给她打上「家庭客户」的标签

这些标签可以帮助您做更精准的营销。比如新品面包上市时，只给「面包爱好者」发通知，避免打扰其他顾客。

## 六、数据看板相关问题

### Q22: 仪表盘上的数据多久更新一次？

**A:** 数据是**实时更新**的。比如：

- 中西区分店刚卖出一个面包，收银系统记录后，您的仪表盘上会立刻看到销售额增加
- 延迟不超过5分钟
- 所以您随时打开手机，看到的数据都是最新的

### Q23: 损耗率是怎么算的？

**A:** 损耗率的计算公式是：

> **损耗率 = (当天报废产品的总成本 ÷ 当天生产产品的总成本) × 100%**

**举个例子：**
- 今天生产了价值10,000元的面包和蛋糕
- 晚上报废了价值1,500元的产品
- 损耗率 = (1,500 ÷ 10,000) × 100% = **15%**

行业平均水平是8%-10%，您的目标是降到10%以下。系统会自动计算并显示在仪表盘上。

### Q24: 我可以看到每个员工的业绩吗？

**A:** 系统目前不追踪个人业绩，但可以看到各门店的业绩。这样可以：

- 知道哪家店卖得最好
- 知道哪家店的损耗率最低
- 作为门店管理的参考依据

如果以后需要统计个人业绩，可以升级系统添加这个功能。

## 七、技术相关问题

### Q25: 系统需要联网吗？断网了还能用吗？

**A:** 系统需要联网使用。如果断网了：

1. **暂时无法访问系统** — 无法查看库存、处理订单等
2. **但收银不受影响** — 收银机是独立的，可以正常收钱
3. **网络恢复后** — 所有数据正常使用，不会丢失

建议店内准备一个备用网络（比如手机热点），以防主网络出故障。

### Q26: 手机和电脑上的数据是同步的吗？

**A:** 是的！所有设备共享同一套数据：

- 在电脑上排好班，手机上马上就能看到
- 在手机上审批了请假，电脑上的排班表自动更新
- 在任何设备上记录的库存变动，所有设备都能看到

因为数据都存储在服务器上，设备只是用来查看和操作的窗口。

### Q27: 系统能跟我的收银机对接吗？

**A:** 目前系统可以手动录入销售数据。如果您的收银机支持数据导出，技术人员可以帮您做对接，实现自动同步。

如果收银机比较老旧（比如还在用老式收款机），建议先手动录入，等以后更换收银机时再做对接。

### Q28: 数据能导出到Excel吗？

**A:** 可以。系统支持将以下数据导出为Excel文件：

- 销售数据
- 库存数据
- 订单列表
- 会员信息
- 排班表

点击页面上的「导出Excel」按钮即可下载。这样您可以用Excel做进一步的分析。

## 九、使用技巧与建议

### Q31: 刚开始用系统，有什么建议吗？

**A:** 建议按以下步骤逐步上手：

**第一周：熟悉基础操作**
- 每天登录系统，看看仪表盘
- 练习新建订单和查看库存
- 让店员开始记录生产和报废

**第二周：全面使用**
- 所有订单都在系统里处理
- 排班改用系统制作
- 开始帮顾客注册会员

**第三周：数据分析**
- 查看第一周的损耗率数据
- 根据数据调整生产计划
- 尝试给会员发送优惠券

**一个月后：完全依赖系统**
- 您会发现已经离不开它了
- 每天花在管理上的时间大幅减少
- 损耗率明显下降

### Q32: 怎么让店员愿意用这个系统？

**A:** 我们建议：

1. **老板带头用** — 您每天用，店员自然跟着用
2. **简单培训** — 我们提供一次现场培训，教会每个人基本操作
3. **明确分工** — 谁负责记录库存、谁负责新建订单，责任到人
4. **正向激励** — 对用得好的员工给予表扬或小奖励
5. **耐心过渡** — 刚开始可能会不习惯，给一周的适应期
