## 一、部署概览

本文档详细说明如何将SweetLoaf数字化管理系统部署到生产环境中。整个部署过程分为以下步骤：

1. **环境准备** — 准备一台服务器（或云主机）
2. **安装依赖** — 安装Python和相关库
3. **配置系统** — 修改数据库、密钥等配置
4. **启动服务** — 正式运行系统
5. **设置开机自启** — 确保服务器重启后系统自动运行
6. **配置域名和HTTPS** — 让员工可以通过网址安全访问

## 二、环境要求

### 2.1 硬件要求

| 项目 | 最低配置 | 推荐配置 |
| :--- | :--- | :--- |
| CPU | 1核 | 2核 |
| 内存 | 1GB | 2GB |
| 硬盘 | 10GB | 20GB SSD |
| 带宽 | 1Mbps | 5Mbps |

> SweetLoaf只有3家门店、12名员工同时使用，最低配置完全够用。如果未来扩展到10家以上门店，建议升级到推荐配置。

### 2.2 软件要求

| 软件 | 版本要求 | 说明 |
| :--- | :--- | :--- |
| **操作系统** | Ubuntu 20.04 / 22.04 LTS | 推荐使用Ubuntu，以下命令基于Ubuntu |
| **Python** | 3.8 或更高版本 | 系统运行的核心环境 |
| **pip** | 最新版 | Python包管理工具 |
| **Nginx** | 最新稳定版 | 用作反向代理，处理HTTPS和域名 |
| **SQLite** | 内置 | 开发环境使用（小规模够用） |
| **PostgreSQL**（可选） | 14+ | 生产环境推荐，数据更安全 |

## 三、详细部署步骤

### 步骤1：准备服务器

#### 选项A：使用云服务器（推荐）

推荐使用以下云服务商：
- **台湾本地：** 远传电信云端、中华电信hicloud
- **国际：** 阿里云（新加坡节点）、AWS（东京节点）

**最低配置建议：** 1核1G内存，20G硬盘，月费约500-1000元新台币

购买后，您会得到一个IP地址和SSH登录密码。

#### 选项B：使用公司内部电脑

如果不想用云服务，也可以用一台不用的电脑当作服务器：
- 安装Ubuntu 20.04 LTS操作系统
- 连接到公司网络，设置固定内网IP（如192.168.1.100）
- 员工通过内网IP访问系统

### 步骤2：登录服务器

打开终端（Mac的"终端"或Windows的"PowerShell"），输入以下命令：

```bash

ssh root@你的服务器IP地址
```

系统会提示输入密码，输入后按回车即可登录。

### 步骤6：配置系统

#### 6.1 修改配置文件

```bash
# 创建配置文件
nano src/config.py
```

将配置文件内容修改如下：

```python
import os

class Config:
    """SweetLoaf系统配置"""
    
    # 数据库配置
    # 开发环境使用SQLite（文件数据库）
    SQLALCHEMY_DATABASE_URI = 'sqlite:///sweetloaf.db'
    
    # 生产环境建议使用PostgreSQL（需要先安装PostgreSQL）
    # SQLALCHEMY_DATABASE_URI = 'postgresql://username:password@localhost:5432/sweetloaf'
    
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    
    # 安全密钥（请务必修改为随机字符串！）
    SECRET_KEY = '请修改为一段随机字符串，越长越安全'
    
    # 服务器配置
    HOST = '0.0.0.0'  # 监听所有网络接口
    PORT = 5000        # 服务端口
```

> ⚠️ **重要安全提醒：** 请务必将 `SECRET_KEY` 修改为一串随机字符！可以使用以下命令生成：
> ```bash
> python3 -c "import secrets; print(secrets.token_hex(32))"
> ```

#### 6.2 初始化数据库

```bash
# 确保在项目目录和虚拟环境中
cd /var/www/sweetloaf
source venv/bin/activate

# 初始化数据库并创建表
python3 -c "
from src.app import app, db
with app.app_context():
    db.create_all()
    print('数据库初始化成功！')
"
```

#### 6.3 创建默认管理员账号

```bash
# 运行初始化脚本，创建默认账号
python3 -c "
from src.app import app, db
from src.models import User
from werkzeug.security import generate_password_hash

with app.app_context():
    # 检查是否已存在管理员
    admin = User.query.filter_by(username='admin').first()
    if not admin:
        admin = User(
            username='admin',
            password=generate_password_hash('admin123'),
            role='admin',
            store='总部'
        )
        db.session.add(admin)
        
        # 创建各门店账号
        manager_east = User(
            username='manager_east',
            password=generate_password_hash('123456'),
            role='manager',
            store='东区店'
        )
        db.session.add(manager_east)
        
        baker1 = User(
            username='baker1',
            password=generate_password_hash('123456'),
            role='baker',
            store='中央厨房'
        )
        db.session.add(baker1)
        
        cashier1 = User(
            username='cashier1',
            password=generate_password_hash('123456'),
            role='cashier',
            store='东区店'
        )
        db.session.add(cashier1)
        
        db.session.commit()
        print('默认账号创建成功！')
    else:
        print('管理员账号已存在，跳过创建。')
"
```

### 步骤8：使用Gunicorn正式启动（生产环境）

Gunicorn是一个高性能的Python Web服务器，比Flask自带的服务器更稳定、更安全。

#### 8.1 安装Gunicorn

```bash
# 如果之前没安装
pip install gunicorn
```

#### 8.2 创建启动脚本

```bash
# 创建启动脚本
nano /var/www/sweetloaf/start.sh
```

写入以下内容：

```bash
#!/bin/bash
# SweetLoaf 系统启动脚本

# 进入项目目录
cd /var/www/sweetloaf

# 激活虚拟环境
source venv/bin/activate

# 使用Gunicorn启动
# -w 4: 启动4个工作进程（根据CPU核心数调整）
# -b 0.0.0.0:5000: 监听所有IP的5000端口
# --timeout 120: 超时时间120秒
# --access-logfile: 访问日志
# --error-logfile: 错误日志
exec gunicorn -w 4 \
              -b 0.0.0.0:5000 \
              --timeout 120 \
              --access-logfile /var/log/sweetloaf/access.log \
              --error-logfile /var/log/sweetloaf/error.log \
              "src.app:app"
```

#### 8.3 创建日志目录并设置权限

```bash
# 创建日志目录
sudo mkdir -p /var/log/sweetloaf
sudo chown -R $USER:$USER /var/log/sweetloaf

# 给启动脚本添加执行权限
chmod +x /var/www/sweetloaf/start.sh
```

#### 8.4 启动系统

```bash
# 手动启动
/var/www/sweetloaf/start.sh
```

### 步骤9：设置系统服务（开机自启）

这样设置后，即使服务器重启，系统也会自动启动。

#### 9.1 创建systemd服务文件

```bash
sudo nano /etc/systemd/system/sweetloaf.service
```

写入以下内容：

```ini
[Unit]
Description=SweetLoaf Bakery Management System
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/sweetloaf
Environment="PATH=/var/www/sweetloaf/venv/bin"
ExecStart=/var/www/sweetloaf/venv/bin/gunicorn -w 4 -b 0.0.0.0:5000 --timeout 120 --access-logfile /var/log/sweetloaf/access.log --error-logfile /var/log/sweetloaf/error.log "src.app:app"
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

#### 9.2 启动服务并设置开机自启

```bash
# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start sweetloaf

# 设置开机自启
sudo systemctl enable sweetloaf

# 查看服务状态
sudo systemctl status sweetloaf
```

如果看到 `active (running)` 的绿色文字，说明服务运行正常。

#### 9.3 常用服务管理命令

```bash
# 查看服务状态
sudo systemctl status sweetloaf

# 重启服务
sudo systemctl restart sweetloaf

# 停止服务
sudo systemctl stop sweetloaf

# 查看实时日志
sudo journalctl -u sweetloaf -f
```

### 步骤10：配置Nginx反向代理和HTTPS（推荐）

通过Nginx可以让员工通过域名（如 `sweetloaf.你的店.com`）访问系统，并配置HTTPS加密，保障数据安全。

#### 10.1 安装Nginx

```bash
sudo apt install -y nginx
```

#### 10.2 配置Nginx

```bash
sudo nano /etc/nginx/sites-available/sweetloaf
```

写入以下内容：

```nginx
server {
    listen 80;
    server_name sweetloaf.你的域名.com;  # 替换为你的实际域名

    # 访问日志
    access_log /var/log/nginx/sweetloaf_access.log;
    error_log /var/log/nginx/sweetloaf_error.log;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 静态文件（如果有）
    location /static {
        alias /var/www/sweetloaf/static;
        expires 30d;
    }
}
```

#### 10.3 启用站点并重启Nginx

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/sweetloaf /etc/nginx/sites-enabled/

# 测试配置是否正确
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```

#### 10.4 配置HTTPS（使用Let's Encrypt免费证书）

```bash
# 安装Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取证书（会引导你完成域名验证）
sudo certbot --nginx -d sweetloaf.你的域名.com

# 证书自动续期（Let's Encrypt证书90天有效）
# Certbot会自动设置定时任务，无需手动操作
```

## 四、数据库备份与恢复

### 4.1 备份数据库

```bash
# 创建备份目录
mkdir -p /var/backups/sweetloaf

# 备份SQLite数据库
cp /var/www/sweetloaf/sweetloaf.db /var/backups/sweetloaf/sweetloaf_$(date +%Y%m%d).db

# 设置定时备份（每天凌晨3点）
sudo crontab -e
# 添加以下行：
0 3 * * * cp /var/www/sweetloaf/sweetloaf.db /var/backups/sweetloaf/sweetloaf_$(date +\%Y\%m\%d).db
```

### 4.2 恢复数据库

```bash
# 停止服务
sudo systemctl stop sweetloaf

# 恢复备份
cp /var/backups/sweetloaf/sweetloaf_20260520.db /var/www/sweetloaf/sweetloaf.db

# 重启服务
sudo systemctl start sweetloaf
```

## 六、故障排查

### 问题1：服务无法启动

```bash
# 查看详细错误信息
sudo journalctl -u sweetloaf -n 50 --no-pager

# 常见原因及解决：
# 1. 端口被占用
sudo lsof -i :5000
# 如果被占用，kill进程或修改端口

# 2. Python依赖缺失
cd /var/www/sweetloaf
source venv/bin/activate
pip install -r src/requirements.txt

# 3. 数据库文件损坏
# 从备份恢复
```

### 问题2：页面加载缓慢

```bash
# 检查服务器负载
top

# 检查内存使用
free -h

# 如果负载过高，增加Gunicorn工作进程数
# 修改 /etc/systemd/system/sweetloaf.service 中的 -w 4 为 -w 8
# 然后重启服务
sudo systemctl daemon-reload
sudo systemctl restart sweetloaf
```

### 问题3：数据库连接错误

```bash
# 检查数据库文件是否存在
ls -lh /var/www/sweetloaf/sweetloaf.db

# 检查文件权限
ls -la /var/www/sweetloaf/sweetloaf.db
# 应该显示 -rw-r--r-- 或类似权限

# 修复权限
sudo chown www-data:www-data /var/www/sweetloaf/sweetloaf.db
sudo chmod 644 /var/www/sweetloaf/sweetloaf.db
```

## 七、安全建议

1. **修改默认密码**：系统上线后，立即让所有员工修改初始密码
2. **定期备份**：至少每天备份一次数据库
3. **防火墙配置**：
   ```bash
   # 只开放必要端口
   sudo ufw allow 22/tcp      # SSH
   sudo ufw allow 80/tcp      # HTTP
   sudo ufw allow 443/tcp     # HTTPS
   sudo ufw deny 5000         # 禁止直接访问Flask端口
   sudo ufw enable
   ```
4. **定期更新**：每月运行 `sudo apt update && sudo apt upgrade -y`
5. **监控异常登录**：定期检查 `/var/log/sweetloaf/access.log` 中的登录记录
