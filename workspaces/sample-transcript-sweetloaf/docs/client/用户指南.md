## 二、快速上手 — 5分钟学会基本操作

### 2.1 如何登录系统？

**您需要准备：**
- 一台能上网的手机、平板或电脑
- 浏览器（Chrome、Safari、Edge都可以，推荐用Chrome）

**操作步骤：**

1. 在浏览器地址栏输入系统网址（例如：`http://sweetloaf.你的域名.com` 或公司内部网址）
2. 您会看到一个登录页面，输入您的账号和密码
   - **陈老板的账号：** `admin`，密码：`admin123`
   - **东区店长账号：** `manager_east`，密码：`123456`
   - **阿旺师傅账号：** `baker1`，密码：`123456`
   - **收银员小美账号：** `cashier1`，密码：`123456`
3. 点击"登录"按钮，即可进入系统

> 💡 **小提示：** 第一次登录后，建议修改密码。点击右上角的"修改密码"即可。

### 2.2 系统主界面长什么样？

登录后，您会看到一个简洁的主页面，分为几个区域：

- **顶部导航栏**：显示当前登录的用户名和退出按钮
- **左侧菜单**：列出所有功能模块（库存管理、销售看板、会员管理、生产管理等）
- **中间主区域**：显示您当前正在操作的内容

## 三、核心功能使用说明

### 3.1 库存管理 — 再也不用担心面包做多了卖不掉

**这个功能解决什么问题？**
以前，中央厨房的阿旺师傅只能凭经验估算每天要做多少面包。做少了，下午就没货卖；做多了，晚上只能打折处理甚至扔掉，白白浪费面粉和人工。现在，系统会实时告诉您每个门店还剩多少面包，让您科学安排生产。

#### 3.1.1 查看库存

1. 点击左侧菜单的「库存管理」
2. 您会看到一张表格，列出所有产品的库存情况
3. 每一行显示：产品名称、总库存数量、各门店的库存数量
4. 您还可以按门店筛选，只看东区店、中西区店或北区店的库存

**举个例子：** 您想知道"台南红豆包"还有多少？打开库存页面，一眼就能看到——东区店还剩12个，中西区店还剩25个，北区店还剩8个。北区店快卖完了，得赶紧补货！

#### 3.1.2 原材料入库（给阿旺师傅看）

当面粉、黄油等原材料到货时：

1. 点击「库存管理」→「原材料入库」
2. 选择原材料名称（如"高筋面粉"）
3. 输入数量（如"50公斤"）
4. 点击「确认入库」
5. 系统会自动更新库存，所有门店都能看到

#### 3.1.3 生产记录（给阿旺师傅看）

每天烤好面包后：

1. 点击「生产管理」→「记录生产」
2. 选择产品名称（如"台南红豆包"）
3. 输入生产数量（如"100个"）
4. 系统会自动扣减面粉等原材料的消耗，并增加成品库存

#### 3.1.4 库存预警 — 系统主动提醒您

这是最实用的功能之一！您可以为每个产品设定"最低库存量"。

**设置方法：**
1. 点击「库存管理」→「预警设置」
2. 找到"台南红豆包"，在"最低库存"一栏输入"15"
3. 点击保存

**效果：** 当东区店的红豆包库存低于15个时，系统会自动向您和店长的手机发送LINE消息：「【库存预警】东区店红豆包库存仅剩12个，请及时补货！」

> 💡 **建议设置：** 热门产品（红豆包、奶酥面包）最低库存设为20个；一般产品设为10个。

### 3.2 销售数据看板 — 手机上看懂生意好不好

**这个功能解决什么问题？**
以前，您需要每天下午给三家店长打电话，或者等他们发LINE消息，才能知道今天总共卖了多少钱。现在，打开手机就能看到实时数据。

#### 3.2.1 查看今日营收

1. 点击左侧菜单的「销售看板」
2. 页面顶部会显示：**今日总营收**、**本周总营收**、**本月总营收**
3. 下方会显示三家门店各自的营收数据，用不同颜色区分
4. 数据是**实时更新**的——收银台每卖出一个面包，这里的数字就会变化

**举个例子：** 现在是上午10点，您打开手机一看：
- 东区店：已卖 ¥3,200
- 中西区店：已卖 ¥2,800
- 北区店：已卖 ¥1,500
- **总计：¥7,500**

您马上就能判断：北区店今天生意比较淡，是不是有什么原因？

#### 3.2.2 查看热销排行榜

想知道今天什么面包卖得最好？

1. 在「销售看板」页面往下滑
2. 您会看到「今日热销TOP10」列表
3. 排名第一的就是今天卖得最好的产品
4. 旁边还有「今日滞销TOP5」，帮您发现哪些产品卖不动

**这个数据有什么用？**
- 如果"台南红豆包"连续一周都是热销第一，说明应该增加产量
- 如果"德式黑麦面包"连续三天都在滞销榜上，可以考虑减少生产，或者做促销活动

#### 3.2.3 按门店和时间筛选

- 您可以选择只看「东区店」的数据
- 也可以选择看「本周」、「本月」或「自定义时间段」的数据
- 方便您对比不同门店、不同时间段的经营情况

### 3.3 会员管理 — 让老顾客变成忠实粉丝

**这个功能解决什么问题？**
以前，顾客买完面包就走了，您不知道谁是老顾客、他们喜欢买什么。现在，系统帮您自动建立会员档案，让您能像朋友一样记住每一位顾客。

#### 3.3.1 帮顾客注册会员（收银员操作）

顾客结账时：

1. 收银员问顾客："请问您有我们的会员吗？报手机号就可以免费加入。"
2. 在收银界面点击「注册会员」
3. 输入顾客的手机号码
4. 系统会自动发送一条欢迎短信：「欢迎加入SweetLoaf会员！您已获得100积分。」
5. 整个过程不超过10秒钟

> 💡 **小技巧：** 可以在收银台放一个小立牌，写上"免费加入会员，消费积分抵现金！"

#### 3.3.2 积分累积与兑换

**积分规则：** 每消费10元累积1积分（例如：买一个45元的红豆包，获得4.5积分）

**顾客想用积分怎么办？**
1. 收银员在收银界面点击「积分兑换」
2. 输入顾客的手机号，系统会显示当前积分
3. 输入要抵扣的金额（例如：100积分可抵扣10元）
4. 系统自动扣减积分，订单金额相应减少
5. 收银小票上会显示："本次积分：5，总积分：120"

#### 3.3.3 会员等级

系统支持设置不同的会员等级，让忠诚的老顾客享受更多优惠：

| 等级 | 升级条件 | 优惠 |
| :--- | :--- | :--- |
| 🥉 普通会员 | 注册即享 | 积分累积 |
| 🥈 银卡会员 | 累计消费满500元 | 9.5折 |
| 🥇 金卡会员 | 累计消费满1500元 | 9折 |

> 您可以在后台自行调整这些规则。

### 3.4 智能生产建议 — 科学决定明天做多少

**这个功能解决什么问题？**
阿旺师傅每天凌晨3点就要开始准备面团，但他常常纠结：今天该做多少个红豆包？做少了不够卖，做多了浪费。现在，系统会基于过去一周的销售数据，自动给出建议生产量。

#### 3.4.1 查看生产建议

1. 每天下午6点后，点击「生产管理」→「生产建议」
2. 系统会生成一张"明日生产建议单"，内容包括：
   - 产品名称
   - 建议生产数量
   - 依据说明（例如："基于过去7天平均销量+15%（明日为周六，销量通常较高）"）
3. 阿旺师傅可以查看并决定是否采纳

#### 3.4.2 手动调整

如果阿旺师傅觉得系统建议不合理（比如明天有学校团购的大订单），可以直接在建议单上修改数量。修改后，系统会记录"已人工调整"，方便您后续追踪。

### 3.5 门店调拨 — 东区店缺货？从北区店调！

**这个功能解决什么问题？**
有时候东区店的红豆包下午2点就卖完了，但北区店还剩不少。以前您可能不知道，或者知道了也来不及调货。现在，店长在系统上点几下就能发起调拨。

#### 3.5.1 发起调拨申请（店长操作）

1. 东区店长登录系统，点击「调拨管理」→「发起调拨」
2. 选择要调拨的产品："台南红豆包"
3. 输入数量："30个"
4. 选择来源门店："北区店"
5. 点击「提交申请」

#### 3.5.2 审批与执行（总店操作）

1. 您（陈老板）或总店管理员会收到调拨申请通知
2. 登录系统查看申请详情
3. 如果同意，点击「审批通过」
4. 系统自动通知配送司机
5. 司机取货后，在手机上点击「已取货」
6. 司机送达后，点击「已送达」
7. 系统自动完成库存增减——北区店减30个，东区店加30个

> 整个过程不需要任何纸质单据，系统自动记录每一步。

### 3.6 营销工具 — 自动给老顾客送优惠

**这个功能解决什么问题？**
以前做促销，只能门口贴海报，效果好不好也不知道。现在，系统可以自动给会员发送优惠信息。

#### 3.6.1 生日自动祝福

- 系统每天早上8点自动检查当天是否有会员过生日
- 自动向过生日的会员发送LINE消息：「SweetLoaf祝您生日快乐！凭此消息到店消费享9折优惠。」
- 顾客到店后，收银员扫描其手机上的优惠码，系统自动打折

#### 3.6.2 创建优惠券活动（陈老板操作）

1. 点击「营销管理」→「创建活动」
2. 设置活动名称："满100减15"
3. 设置活动规则：消费满100元减15元
4. 选择推送对象："过去30天未消费的会员"
5. 点击「发布活动」
6. 系统自动向符合条件的会员推送优惠券

## 四、常见操作场景（情景教学）

### 场景一：早晨开店流程

**阿旺师傅（中央厨房）：**
1. 凌晨到店，打开系统查看「生产建议」
2. 根据建议调整生产数量，开始烘焙
3. 面包出炉后，在系统记录「生产入库」
4. 配送司机根据系统生成的配送单，将面包送往各门店

**各门店收银员：**
1. 到店后打开系统，确认今日到货的面包数量
2. 开始营业，每卖出一个面包在POS机上操作
3. 遇到新顾客，主动邀请注册会员

**陈老板：**
1. 在家打开手机，查看「销售看板」
2. 看看各店早上的销售情况
3. 如果有门店库存预警，及时安排调拨

### 场景二：下午补货流程

1. 东区店的红豆包快卖完了，系统自动发送预警
2. 东区店长在系统发起「调拨申请」
3. 您（陈老板）在手机上审批通过
4. 配送司机收到通知，从总店取货送往东区店
5. 司机确认送达，库存自动更新

### 场景三：月底对账

1. 打开「销售看板」，选择"本月"
2. 查看三家门店的营收总和和各自数据
3. 查看「热销排行榜」，分析本月哪些产品卖得好
4. 查看「滞销排行榜」，考虑下个月是否减少生产
5. 所有数据一目了然，不需要再打电话问各店长

## 五、账号与权限说明

不同岗位的员工能看到和操作的内容不同，这样既保护数据安全，又避免误操作。

| 角色 | 能看到什么 | 能做什么 |
| :--- | :--- | :--- |
| **陈老板（admin）** | 所有数据：三家店的营收、库存、会员信息 | 所有操作：创建活动、审批调拨、查看报表 |
| **店长（manager_xxx）** | 自己门店的数据 | 发起调拨、查看本店库存和销售、管理本店员工 |
| **师傅（baker）** | 库存和生产相关数据 | 记录生产、查看生产建议、管理原材料 |
| **收银员（cashier）** | 收银和会员相关 | 收款、注册会员、积分兑换 |

## 六、遇到问题怎么办？

### 常见小问题

**Q：登录时提示"账号或密码错误"？**
A：检查是否输入正确的大小写。如果忘记密码，联系陈老板在后台重置。

**Q：页面加载很慢怎么办？**
A：先检查网络是否正常。如果网络没问题，可能是同时使用的人太多，稍等一分钟再试。

**Q：不小心输错了生产数量怎么办？**
A：联系陈老板或管理员，可以在后台修改记录。不要重复录入，否则库存会出错。

**Q：顾客说没收到生日优惠消息？**
A：请顾客检查LINE消息。如果确实没收到，收银员可以手动输入会员手机号查询，手动给予优惠。

### 需要帮助时联系我们

- **系统使用问题：** 先问问店长或其他同事
- **技术故障：** 联系我们的技术支持团队（联系方式见部署指南）
- **功能建议：** 欢迎随时向陈老板反馈，我们会持续改进系统
