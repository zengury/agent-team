## 二、登录与首页介绍

### 2.1 如何登录系统？

**电脑端：**
1. 打开电脑上的浏览器（Chrome、Edge、Safari都可以）
2. 在地址栏输入系统网址（技术人员会给您一个网址，例如 `http://sweetloaf.您的店名.com`）
3. 输入您的账号和密码（首次登录时技术人员会给您设置好）
4. 点击「登录」按钮

**手机端：**
1. 在手机浏览器中输入同样的网址
2. 输入账号密码登录
3. 建议把网页添加到手机桌面，以后点一下就能打开（iPhone用Safari的「分享-添加到主屏幕」，安卓用Chrome的「添加到主屏幕」）

### 2.2 首页长什么样？

登录后，您会看到一个**数据仪表盘**，就像汽车的中控台一样，一眼就能看到最重要的信息：

- **今日总销售额** — 三家店今天一共卖了多少钱
- **各店实时销售额** — 东区总店、中西区分店、南区分店分别卖了多少
- **销量TOP5产品** — 今天卖得最好的5种面包/蛋糕是什么
- **库存预警** — 哪些原料快用完了，需要赶紧进货
- **待处理订单** — 今天有哪些生日蛋糕或团购订单要交付
- **今日损耗率** — 今天报废了多少产品，占比多少

> 💡 **小窍门：** 每天早上打开手机看一眼仪表盘，就能掌握全店经营状况，不用再一家店一家店跑了。

## 三、库存管理 — 再也不用"拍脑袋"进货了

这是系统最核心的功能，帮您解决"面粉买多了用不完、面包做多了卖不掉"的问题。

### 3.1 查看实时库存

点击左侧菜单的「库存管理」，您会看到三家店的库存情况：

- **原料库存**：面粉、黄油、奶油芝士、糖、鸡蛋等所有原料的实时数量
- **成品库存**：各店目前还有多少面包、蛋糕可以卖
- **可按门店筛选**：想看哪家店，点一下就能切换

**举个例子：** 以前您想知道东区总店还有多少高筋面粉，得打电话问主厨或者亲自跑去看。现在打开系统，一眼就能看到："东区总店 — 高筋面粉 — 剩余35公斤"。

### 3.2 记录原料入库（进货）

当供应商送货来时，操作很简单：

1. 点击「库存管理」→「入库登记」
2. 选择门店（送到哪家店就选哪家）
3. 选择原料名称（比如"高筋面粉"）
4. 输入数量（比如"50公斤"）
5. 选择供应商（可选）
6. 点击「确认入库」

系统会自动更新库存数量，以后查库存时就能看到最新数据。

### 3.3 记录原料出库（生产领用）

当后厨从仓库领用原料做面包时：

1. 点击「库存管理」→「出库登记」
2. 选择门店和原料名称
3. 输入领用数量
4. 点击「确认出库」

### 3.4 记录成品生产和报废

每天生产了多少面包、卖了多少、报废了多少，都要记录下来：

**记录生产：**
1. 点击「生产管理」→「新增生产记录」
2. 选择门店和产品名称（比如"台南桂圆核桃面包"）
3. 输入生产数量（比如"50个"）
4. 点击「确认」

**记录报废：**
1. 点击「库存管理」→「报废登记」
2. 选择门店和产品名称
3. 输入报废数量和原因（比如"未售出"或"品质问题"）
4. 点击「确认」

> 💡 **为什么要记录报废？** 记录一段时间后，系统会自动算出每天的损耗率。您就能知道："原来每周三的面包损耗最高，以后周三可以少做一些"。

### 3.5 库存预警与补货建议

这是系统的"智能提醒"功能，特别实用！

当某种原料快用完时，系统会自动提醒您。比如：

- 您设定了"高筋面粉"的安全库存是50公斤
- 当库存低于50公斤时，系统会在仪表盘上显示**红色预警**
- 同时，系统会根据最近7天的平均用量，自动算出建议采购量

**举个例子：** 高筋面粉还剩40公斤，过去7天平均每天用15公斤，供应商送货需要2天。系统会建议您采购：
> (15公斤/天 × 2天) + 50公斤（安全库存）- 40公斤（当前库存）= **建议采购40公斤**

您只需要看一眼建议，觉得合适就点「生成采购单」，不合适就手动改一下数字。

## 四、订单管理 — 再也不怕漏单、记错日期

### 4.1 新建订单

当顾客打电话来预订生日蛋糕或公司团购时：

1. 点击「订单管理」→「新建订单」
2. 填写客户姓名和电话
3. 选择产品（比如"芒果乳酪蛋糕"）
4. 输入数量
5. 选择取货日期和时间
6. 备注特殊要求（比如"蛋糕上写'生日快乐'"）
7. 点击「确认」

系统会自动把这个订单加到日历里，再也不会出现"记在小纸条上弄丢了"的情况。

### 4.2 订单日历视图

点击「订单管理」→「日历视图」，您会看到一个日历：

- 有订单的日期下面会显示数字（比如"5单"）
- 点击日期，会列出当天所有订单的详情
- 可以看到：客户名、产品、数量、取货时间、状态（已确认/已完成/已取消）

**特别提醒：** 如果某个时间段订单太多，系统会弹出警告。比如下午4点到5点已经有10个订单要取货，系统会提醒您："该时段订单量较大，可能忙不过来，请确认是否继续接单？"

### 4.3 订单状态跟踪

每个订单都有状态，一目了然：

| 状态 | 含义 |
|:---|:---|
| ⏳ 待确认 | 刚创建，还没跟客户确认 |
| ✅ 已确认 | 跟客户确认过了，准时做 |
| 🔄 制作中 | 后厨正在做 |
| 📦 已完成 | 客户已取走 |
| ❌ 已取消 | 客户取消或订单作废 |

## 五、员工排班 — 告别Excel手工排班

### 5.1 查看排班表

点击「排班管理」，您会看到一张清晰的排班表：

- 横轴是日期（周一至周日）
- 纵轴是员工名字
- 每个格子显示员工当天的班次（早班/晚班/休息）

### 5.2 创建排班

1. 点击「排班管理」→「新建排班」
2. 选择门店（东区总店/中西区分店/南区分店）
3. 选择员工
4. 选择日期和班次
5. 点击「保存」

支持拖拽操作，非常方便。比如张三周一上早班，直接把"张三"拖到"周一早班"的格子里就行。

### 5.3 员工自助调班/请假

这个功能可以帮您省很多事！

**员工操作（手机端）：**
1. 员工登录自己的账号
2. 点击「排班」→「申请调班」或「申请请假」
3. 填写申请信息（调班：和谁换、换哪天的班；请假：哪几天、什么原因）
4. 提交申请

**老板操作（审批）：**
1. 您会收到一条审批通知
2. 打开看看申请内容
3. 觉得合理就点「批准」，不合理就点「拒绝」
4. 系统会自动更新排班表

> 💡 **好处：** 以前员工调班要打电话找您，您再手动改Excel。现在员工自己提交申请，您在手机上点一下就能批，省时又省力。

## 六、会员管理 — 让老顾客愿意常来

### 6.1 帮顾客注册会员

当顾客结账时，店员可以问一句："要不要注册会员？以后可以积分换优惠哦！"

注册方法很简单：
1. 点击「会员管理」→「新增会员」
2. 输入顾客的手机号码
3. 输入顾客的姓名（可选）
4. 点击「确认」

系统会自动记录这位顾客以后的每次消费。

### 6.2 查看会员信息

点击会员名字，可以看到：

- 累计消费金额
- 累计积分
- 最近一次消费时间
- 消费偏好标签（系统自动生成，比如"面包爱好者"、"蛋糕控"、"高客单价客户"）

### 6.3 给会员发优惠

**手动发优惠：**
1. 在会员列表中找到想发优惠的顾客
2. 点击「发送优惠券」
3. 选择优惠内容（比如"满100减20"）
4. 点击「发送」

**自动营销（更省事）：**
系统可以帮您自动做这些事情：

- **生日祝福：** 系统会自动检测会员的生日（如果登记了），提前一天提醒您，您可以给顾客发一张生日优惠券
- **新品通知：** 当您推出新口味面包时，可以一键通知所有"面包爱好者"标签的会员
- **沉睡唤醒：** 如果某个会员超过30天没来消费，系统会提醒您给他发一张"欢迎回来"优惠券

## 七、数据看板 — 用数据说话，不再凭感觉

### 7.1 每日必看

每天早上，建议您花1分钟看这几个数据：

1. **昨日总销售额** — 比前天涨了还是跌了？
2. **昨日损耗率** — 正常应该在10%以下，如果超过15%就要找原因
3. **今日订单量** — 今天有多少预订要交付
4. **库存预警** — 有没有需要紧急补货的原料

### 7.2 每周分析

每周日晚上，花5分钟看：

1. **本周各店销售额排名** — 哪家店卖得最好？哪家店需要改进？
2. **本周销量TOP10产品** — 哪些产品最受欢迎？要不要加大生产？
3. **本周损耗率趋势** — 损耗率在下降吗？说明库存管理在进步

### 7.3 数据钻取功能

看到某个数据想了解更详细的信息？直接点击它！

**举个例子：** 在仪表盘上看到"台南桂圆核桃面包"是销量冠军，点击它，就能看到：
- 三家店分别卖了多少个
- 各店还有多少库存
- 今天报废了几个
- 过去一周的销量趋势

## 八、常见操作小贴士

### 8.1 每天下班前必做的3件事

1. **记录报废：** 今天没卖完的面包，在系统里登记报废数量和原因
2. **核对销售：** 确认今天的销售数据已经同步到系统
3. **查看明日订单：** 看看明天有哪些预订，提前做好准备

### 8.2 每周一必做的2件事

1. **检查库存预警设置：** 看看各种原料的安全库存设置是否合理
2. **查看会员数据：** 看看上周新增了多少会员，有没有需要发送的优惠

### 8.3 遇到问题怎么办？

- **忘记密码：** 点击登录页的「忘记密码」，输入手机号即可重置
- **数据不对：** 检查是不是有人忘了记录入库或出库
- **系统卡顿：** 刷新页面试试，或者联系技术支持

## 九、给不同角色的操作指南

### 9.1 陈老板（老板/管理者）

**每天必看：** 仪表盘（销售额、损耗率、预警）
**每周必做：** 审批排班申请、查看经营分析
**重点关注：** 利润、损耗、客户增长

### 9.2 店长（各门店负责人）

**每天必做：** 记录生产、报废、核对库存
**每周必做：** 提交下周排班建议
**重点关注：** 本店库存、员工出勤、客户满意度

### 9.3 店员（一线员工）

**每天必做：** 帮顾客注册会员、记录销售
**需要时做：** 提交调班/请假申请
**重点关注：** 自己的排班、库存预警通知
